# Windows10-Cleanup-Script

A safe and practical PowerShell toolkit for cleaning and organizing Windows 10 systems.

## What this repo includes

- `CleanWindows10.ps1` — streamlined GUI cleanup tool for everyday use
- `CleanupUtility.ps1` — advanced utility with backup, restore-point, dry-run, and richer controls
- Support for cleaning temporary files, browser caches, prefetch, logs, recycle bin, and organizing Downloads/Desktop

## New features added

- Dry-run preview mode
- Backup of deleted files before removal
- Restore point creation support
- Better logging and app data storage
- Improved progress and status reporting
- Safer file handling and error resilience
- Validation checks for common cleanup targets

## How to run

```powershell
powershell -ExecutionPolicy Bypass -File .\CleanWindows10.ps1
```

or

```powershell
powershell -ExecutionPolicy Bypass -File .\CleanupUtility.ps1
```

## Important note

This tool removes data from common Windows temporary and cache locations. Use the dry-run mode first and enable backups when working with important files.

## Safety recommendations

- Run in dry-run mode first
- Enable backup mode before large cleanup jobs
- Ensure you have a restore point before deleting system-related cache
